Operation mode

Passthrough bridges USB serial to the leader servo bus at 1 Mbaud (PlatformIO monitor is set to 1000000 for leader). On the controller: cycle to passthrough, then press A to confirm or B to cancel. Applying passthrough here activates it immediately. Use the follower hardware switch for wired LeRobot on the follower arm.

PC serial bench (profile 5) sends mirror batches to the follower over USB COM. The dashboard reads leader positions over Wi-Fi and writes binary frames to the follower port (leader USB not required). Apply profile 5, start the COM mirror below, then start continuous mirror.
